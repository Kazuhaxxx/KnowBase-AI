# Approved Software Catalog & Installation Guidelines

**Document ID:** KB-SW-008  
**Organization:** NovaTech Global (Fictional Demo Knowledge Base)  
**Classification:** Employee  

## 1. Installing Pre-Approved Applications via Company Portal
Standard employees do not hold local administrator rights on corporate laptops.
1. Open the **Company Portal** app (Windows) or **NovaTech Self Service** (macOS).
2. Browse or search the **Approved Software Catalog** (includes VS Code, Python 3.11, Git, Docker Desktop, Slack, Zoom, Postman, and Adobe Acrobat Reader).
3. Click **Install**. Installation runs silently using signed enterprise packages without requiring an admin password.

## 2. Requesting Non-Standard or Licensed Software
If an application is not listed in Company Portal (e.g., JetBrains IntelliJ Ultimate, Figma Paid Seat, Tableau Desktop):
1. Submit a **Software Procurement & Security Review** request in the Service Portal.
2. Provide business justification, vendor privacy policy link, and manager cost-center approval.
3. Security Engineering completes a **5-business-day** vendor assessment before packaging.

## 3. Prohibited Software & Unmanaged Installers
**Important:** Never download executable installers (`.exe`, `.msi`, `.dmg`, `.pkg`) from unverified third-party mirrors or bypass SmartScreen/Gatekeeper warnings.
- Browser extensions that capture full page contents or proxy traffic without security approval are blocked by policy.
- Personal cloud sync tools (Dropbox Personal, Google Drive Personal) are restricted on managed corporate endpoints.
